# Manifest v8.3 closure review

## Corrections from the calibration experiment

The Revue CZ-rate-derived Guaranteed Minimum Exposure is withdrawn. Public sources establish the five-color LED setting-difference distribution at fake-premonition/CZ-end contexts, while a detailed source specifies fake-premonition end / CZ failure. Aggregate CZ occurrence therefore does not prove that every CZ occurrence creates an eligible setting-difference LED trial.

Revue LED remains LIVE_CONDITIONAL with an exhaustive five-color multinomial likelihood. Its 7000G benchmark exposure is UNRESOLVED until a public eligible-opportunity rate or another proven contained event class is found. Earlier provisional guaranteed scores are withdrawn.

The earlier statement that v8.2 lacked per-trial conditional information metadata is also corrected. SEL-008C already required deterministic per-observed-trial information. v8.3 only canonicalizes IGPerEligibleTrial and strengthens its non-score guardrails.

## Minimal justified v8.3 delta

1. Deterministic construction for a proven DERIVED_LOWER_BOUNDED score.
2. Exact preservation of source denominator semantics; contextual location must not relabel a denominator.
3. Canonical IGPerEligibleTrial naming and explicit prohibition on turning it into SelectionScore without benchmark exposure.

## Closure assessment

The calibration does not justify additional complexity beyond these three clarifications. Guaranteed Minimum Exposure remains a generic capability, but neither reference calibration should be used as proof that a lower-bound premise exists unless the source-supported containment relation itself is established.
