# Manifest v8.2 cross-machine calibration review

Machines:
- S_REVUE_STARLIGHT_CX
- L_MUSHOKU_TENSEI

## What reproduced correctly

1. Conditional observations were independently rediscovered from public information.
2. Revue LED required bounded benchmark exposure; Mushoku did not require that mechanism for its currently resolved primary paths.
3. Runtime-observable conditional denominators remained distinct from benchmark exposure.
4. Dependency-safe construction prevented parent/child double multiplication.

## Revue

The five-color LED observation is a single exhaustive categorical observation. Exact benchmark opportunity count is not public, while CZ occurrence provides a potential guaranteed-minimum relation. Therefore v8.2's lower-bound mechanism is materially useful here.

Open issue: the current guaranteed-minimum scoring text is not sufficiently deterministic when the lower expected exposure differs by setting and is fractional. A generic rule is required before the provisional numeric guaranteed score can be treated as canonical.

## Mushoku

Primary benchmark-scored candidates can be constructed without lower-bound exposure. Several other observations are LIVE_CONDITIONAL with complete setting-specific likelihood but unresolved benchmark opportunity frequency.

Examples:
- Shirone destination among eligible non-Hitogami transitions
- white-cell -> Hitogami
- Yoken-eye activation
- CZ nonmatching-role success

Per-eligible-trial mutual information can be computed reproducibly, but v8.2 does not define a canonical field or role for this value.

## Manifest gaps exposed by both calibrations

### Gap A — deterministic Guaranteed Minimum IG

For DERIVED_LOWER_BOUNDED, define how a setting-dependent/fractional lower exposure becomes the benchmark observation model. Do not let each machine implementation choose floor/min/Poisson independently.

### Gap B — exposure-independent conditional strength

For complete LIVE_CONDITIONAL likelihoods whose benchmark exposure is unresolved, preserve IG per eligible trial as diagnostic Selection metadata. It must not become SelectionScore, an importance tier, or a fabricated 7000G exposure.

### Gap C — source denominator semantics

A published 'effective occurrence rate' must retain its source denominator semantics. A contextual location such as 'during AT' does not authorize relabeling the denominator as AT games.

## Recommendation for the next Manifest revision

Amend the Manifest generically before treating either calibration as final Selection:
- canonicalize guaranteed-minimum benchmark construction;
- add per-eligible-trial IG metadata for unresolved-benchmark conditional observations;
- explicitly prohibit denominator relabeling without source proof.

Research facts already obtained under v8.2 can remain source facts; affected Exposure/Selection construction should be regenerated after the amendment.
