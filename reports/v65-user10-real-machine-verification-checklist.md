# SloAnalytica v6.5 User-selected 10 — 実機確認票

作成日: 2026-08-30
対象branch: `prototype-multi-machine`

## 目的

Research → Selection → Observation → UI Design → MachineData Build → Batch Publish → 全体Audit完了後に残った、Webだけでは確定できない実機観測項目を10機種まとめて確認する。

- 連動サービスの**存在確認は不要**。確定状態は次の通り。
  - パチスロ幼女戦記: FOUND（マイスロ）
  - スマスロスーパーブラックジャック: FOUND（スロプラNEXT）
  - スマスロ シャーマンキング: FOUND（ユニメモ）
  - その他7機種: CHECKED_NONE
- `CHECKED_NONE` の7機種では連動サービスの確認を行わない。
- 項目が存在しない場合は「なし」で完了扱い。推測して埋めない。
- 外部データカウンターは店舗ごとに仕様が異なるため、正式なObservation source・実機監査対象にしない。
- 着席時入力は設定推測に利用価値がある機種にのみ設置し、データカウンター・筐体メニュー・履歴表示等を参考にした入力はユーザー自己責任とする。

## 共通の確認方法

各機種では、設定推測Featureの観測に有用な**筐体固有のメニュー・表示**だけを確認する。外部データカウンターの仕様確認は行わない。

着席時入力欄は「前任者区間の値を推測に利用できるか」で設置を決め、値の取得元そのものはSloAnalyticaが保証しない。

## 写真を撮る場合の最小セット

- 各機種: 筐体メニューの累計/履歴ページ 1〜数枚
- 幼女戦記: マイスロ遊技結果/カウンタ項目画面
- SBJ: サブ液晶の累積通常G。可能ならREG前後
- シャーマンキング: ユニメモ遊技結果の項目一覧

## 判定ルール

- 表示あり → 項目名・値の意味・リセット条件をObservationへ反映する。
- 表示なし → `NOT_REQUIRED` / `CHECKED_NONE` 相当として閉じる。
- 表示はあるが意味不明 → 推測せずUNRESOLVEDを維持する。
- 実機確認でMachineData/UIの意味が変わる場合 → Observation → UI Design → Build → Publish → Auditを再実行する。
