## 実施範囲

元の調査は制限付き終了であり、今回も全サイトを再調査したとは主張しない。必要な原表の数値・設定区分・条件だけを限定照合した。未確認の数値、観測できない内部状態、競合する資料は保留理由と元パラメータを残した。外部の独立監査は実施していない。
