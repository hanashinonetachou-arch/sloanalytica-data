- ハードボイルド: 通常時REG終了時のAT当選抽選の値を照合。ただしREG中レア役当選との識別問題あり。
- 炎炎ループの設定6は1/537と1/573の対立記録を維持。設定6の該当指標は評価隔離。

## モデル設計（全機種共通）
- ゲーム数率: 適格なnゲーム中イベントk、確率p=1/N。通常Gと総Gを機種ごと区別。連チャン区間を除く。
- 成功率: 特定条件の抽選機会nと成功kがどちらも実測可能な場合にのみ二項モデル。
- ボーナス合算とBIG/REG内訳、CZ総数とCZ内訳は同一事象であり、独立尤度の多重積禁止。条件付きも同様。
- 分類率: 全選択肢の公表率が揃い互いに排他なら多項モデル。値欠損なら全セクション「記録のみ・推測計算には使用しない」。
- 示唆: 設定確定/否定は確定条件・表示機会検証後にExact Constraint。示唆濃厚/推定は記録のみ。
- フラグ識別が実機入力で不可能なものは数値があっても採用せず、理由を残す。
- 終了画面・ボイス等は同一観測機会でタブ統合。ゲーム数母数は共通入力から自動取得する。
- 不採用理由などユーザー向け文面に参考サイト名を露出させない。
