# クレアBT 8.5.4 同時当選の表示・母数共通化
2026-10-26 / LB_CREA_BONUS_TRIGGER_A2

ユーザー指示：小役別のボーナス同時当選は4役を同時表示。成立回数の入力はチェリーのみ残し、他3役は通常時入力から参照する。

## 仕様
- 4役をOBS_CREA_ROLE_OVERLAPへ統合し、同時当選の4タブを廃止。BIG終了画面のスタンプ/トロフィー2タブは維持。
- チェリーは従来の専用成立回数を維持。
- チャンス目はNORMAL_9.successCount、スイカはNORMAL_6.successCount、滑りスイカはNORMAL_7.successCountを条件付き二項の母数に使用。スイカ合算は使用しない。
- 3つの参照母数は編集不可。セクション内の編集欄はチェリー母数1つ＋4つの同時当選回数の計5つ。
- 同時当選回数と成立回数は同じ区間。途中から同時当選を記録し始めた区間を、自動的に正しい観測へ昇格させない。
- 3役の旧専用母数・旧分子は保存したまま、新しい共通母数へ自動結合しない。同時当選の新入力IDへ同じ区間の回数を再入力する。旧母数と参照母数の数が一致しても自動採用しない。
- 参照元を減らす/消去すると、その役の同時当選は再入力まで停止。上方への継続カウントは反映。フラグと明示0は保存・復元する。
- 8.5.3保存データの通常時の観測契約は変えず、既存の区間確認状態を維持。

Crea専用アダプター、状態説明、Creaデータ、任意のCrea参照表示のみ。参照表示は既存Crea明示フラグがある場合だけ描画し、他機種の表示は変えない。
