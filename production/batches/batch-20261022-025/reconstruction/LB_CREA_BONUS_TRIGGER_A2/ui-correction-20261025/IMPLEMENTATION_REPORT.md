# クレアBT 8.5.3 入力・保存・UI限定是正
2026-10-25 / LB_CREA_BONUS_TRIGGER_A2

## 修正
- 明示0を保存形式v3から復元するCrea限定分岐を追加。
- BIG/REG、スイカ/滑りスイカの合算は両内訳が観測済みの場合に内部計算。片方だけなら単独要素へフォールバック。合算の重複入力欄は削除。
- 旧合算の単独保存は保持。内訳を編集した後に古い合算が復活しない。
- 単独小役3分類は明示0を含めて全項目の観測が必要。その他Gは対象総Gから内部計算し、入力欄を削除。欠落・負の残余はその要素を計算に使わない。
- ゲーム数は総Gの開始/現在のみ。通常時の対象区間を入力すること、ボーナス/BT/成立後を除くこと、対象外を含む台カウンターをそのまま転記しないことを説明。公開確率との母数完全一致は主張しない。
- 同時当選は4役を1セクションの4タブに整理。成立回数/同時当選回数を区別。異なる区間の通常小役回数と自動結合しない。
- BIG終了画面はスタンプ/トロフィーの2タブ。REGカードの同一REG条件を維持。
- 英語内部ラベルを日本語化し、重複説明を整理。狭幅の数値入力余白を改善。
- 旧セッションは値を保持し、通常時関連の観測区間を確認するまで該当の推測を停止。BTと確定演出は独立して利用可能。
