## A. 配信・機種管理

- [ ] アプリを起動してエラー画面にならない。
- [ ] 機種カタログに対象機種が正しい表示名・メーカー名で表示される。
- [ ] 対象機種を「マイ機種」へ追加できる。
- [ ] 重複追加が防止される。
- [ ] 機種を切り替えても、別機種の入力値が混ざらない。
- [ ] 対象機種を削除できる。
- [ ] 削除後に再追加できる。

## B. 入力画面

- [ ] 入力項目の名称・単位・説明がMachineDataの意図どおりに表示される。
- [ ] 数値入力、カウンター、選択肢、チェックボックスが操作できる。
- [ ] `+1`、`+50`などのクイック加算が正しい値だけ増やす。
- [ ] 入力の最小値・最大値・選択範囲が正しく制限される。
- [ ] 条件付き入力・折りたたみ項目が正しい条件で表示／非表示になる。
- [ ] auto accumulatorを使う場合、選択値・条件・除外値・手動補正が仕様どおり反映される。
- [ ] 機種切替後に戻ると、対象機種の入力内容が復元される。

## C. 設定推測

- [ ] 入力なしまたは最少入力でも、クラッシュせず安全に表示される。
- [ ] 代表的な入力値で計算できる。
- [ ] 推定設定確率の合計が100%になる。
- [ ] Featureごとの対象試行回数・信頼度・影響度が表示される。
- [ ] `DISPLAY_ONLY`のFeatureが推定設定確率へ影響しない。
- [ ] 設定別確率比較・参考記録が表示崩れしない。
- [ ] 不正または極端な入力でも、NaN・Infinity・白画面にならない。

## D. Evidence

- [ ] 設定確定・否定の入力が可能である。
- [ ] Evidence適用後、対象外設定が除外される。
- [ ] 複数Evidenceを同時に適用できる。
- [ ] 矛盾するEvidenceでは、安全な判定不能表示になる。
- [ ] Evidenceを解除すると推測結果が正しく戻る。

## E. 履歴

- [ ] 計算結果を履歴へ保存できる。
- [ ] 履歴一覧に対象機種名・ゲーム数・日時が正しく表示される。
- [ ] 履歴詳細に入力・結果・Feature影響度が表示される。
- [ ] 履歴を削除できる。
- [ ] 保存上限到達時の整理導線が動作する。
- [ ] アプリ再起動後も、必要な入力・履歴・マイ機種が保持される。

## F. MachineData更新

- [ ] 更新対象MachineDataのバージョンを上げた状態で更新通知が出る。
- [ ] 更新後、対象機種の入力・履歴・登録状態が保持される。
- [ ] 更新後の新しい入力項目・説明・Featureが正しく表示される。
- [ ] 更新失敗時は旧MachineDataのまま安全に使える。

## G. 表示・回帰確認

- [ ] ライトモードで可読性・配色・コントラストに問題がない。
- [ ] ダークモードで可読性・配色・コントラストに問題がない。
- [ ] 小型画面で入力・結果・上部タブが操作できる。
- [ ] 既存の別機種を1機種以上開き、入力・計算・履歴に回帰がない。
