# 設定帯判別G v1.0

## 定義

**設定帯判別G**  
低設定側・高設定側のどちらに属するかを、各正解率で判別できるようになるゲーム数の目安です。

## 設定帯

- 低設定側: SET_1 / SET_2 / SET_3
- 高設定側: SET_4 / SET_5 / SET_6
- SET_Lなど数値設定として扱わない特殊設定は対象外
- 存在しない設定は単純に省略する

## 事前確率

- 低設定側: 50%
- 高設定側: 50%
- 各設定帯の内部では、存在する設定を等確率とする
- 実ホールの投入率は使用しない

## 使用する推測要素

MachineData生成元のSelectionで `INCLUDE_PRIMARY` または `INCLUDE_SUPPORT` として採用され、かつ `difficultyParticipation !== EXCLUDE` で、ゲーム数に対する `difficultyExposure` を解決できる数値要素のみを使用する。

確定・否定系の設定示唆、着席時の前任者スナップショット、ゲーム数との対応を定義できない推測要素は含めない。

推測時はMachineDataと同じFeature weightを使用する。

## 判定

各シミュレーションで全設定の事後確率を算出し、低設定側の事後確率合計と高設定側の事後確率合計を比較して設定帯を判定する。

## 正解率の到達条件

60% / 70% / 80% の各閾値について、以下を**両方**満たす最小ゲーム数を設定帯判別Gとする。

- 真の設定が低設定側の場合の平均正解率 >= 閾値
- 真の設定が高設定側の場合の平均正解率 >= 閾値

各設定帯の平均正解率は、その帯に存在する各設定を同数シミュレーションした結果の平均とする。

全設定をまとめた平均だけが閾値を超えても到達扱いにはしない。

## 表示

- 60% / 70% / 80% を表示する
- 最終表示は100G単位
- 上限による丸め表示は行わない。極端に大きい値も算出値をそのまま表示する

例:

- 60%: 約2,400G
- 70%: 約5,900G
- 80%: 約14,900G

## シミュレーション

- Monte Carlo方式
- 固定seedを使用し再現可能にする
- 既存Difficultyと同じ確率モデル、Feature weight、difficultyExposureを利用する
- 粗探索500G刻み、閾値付近は100G刻みで再探索する
- 既定の最大探索範囲は100,000G。到達しない場合は内部的に未到達として保持する

## Difficultyとの役割分担

- **設定推測難易度**: 個別設定まで含めた機種全体の設定判別性能を比較する指標
- **設定帯判別G**: 低設定側 / 高設定側という二群分類が何Gでどの程度可能になるかを示す指標

設定帯判別Gは遊技の継続・終了、収益、期待値を推奨する指標ではなく、設定帯の統計的分類性能を示す。
