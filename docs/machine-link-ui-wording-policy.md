# 実機連動機能のユーザー向け表記方針

ユーザー向けMachineData UIでは、実機連動サービスの固有名（例: ユニメモ、打-WIN、スロプラNEXT、マイスロ）をセクション名・入力名・説明文・結果説明に原則表示しない。

## 表示ルール

- セクション名は観測対象そのものを表す。例: `BIG中`、`REG中`、`通常時小役`。
- 実機連動機能から取得した方が入力精度または利便性が明確に向上する項目は、説明文末尾に `（実機連動機能推奨）` を付ける。
- BIG/REGなどデータカウンターで容易に確認できる項目には、原則として推奨表記を付けない。
- ResearchDataやSelectionDataの内部調査根拠では、実際のサービス名を正確に保持してよい。
- ユーザー向けMachineDataへ固有サービス名を露出させる必要がある場合は、公式連携・公認と誤認されない必要最小限の事実説明に限定する。

## 例

- `BIG中の斜め風鈴（風鈴B）の回数を入力してください。（実機連動機能推奨）`
- `花火GAME中のハズレ回数を入力してください。（実機連動機能推奨）`
