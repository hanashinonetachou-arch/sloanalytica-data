## 2026-10-26 user specification supersession: ジャグラー系ブドウ推測値
User approved **using the mean of each independent site's original real-play grape rate by setting** as the reference likelihood for every Juggler machine. This supersedes earlier blanket "grape record-only because manufacturer unpublished" wording. It DOES NOT classify the resulting values as manufacturer-published, nor exempt likelihood from the normal v8.5 Evaluation/Eligibility scoring thresholds.
Required before numeric use:
1. Identify exact model, setting, denominator, and raw independent real-play source. No previous-machine simulator data, reverse-calculated payout estimates, copied tables, theoretical guesses or same original report syndicated on several sites counted as distinct sources. A site's multiple independent tests on the same model & setting should first be combined by hits/trials at SITE level; site gets one vote.
2. For site i with n grape hits over g eligible normal spins, p_i=n/g; if only one published 1/d_i rate available, p_i=1/d_i and mark lower provenance confidence. Use UNWEIGHTED SITE MEAN p_bar = sum(p_i)/number_of_independent_sites. Then report reciprocal d_bar=1/p_bar as 1/d_bar for display. Never average reciprocals d_i directly, and never allow a single high-volume site to silently dominate equal-site averaging. Preserve raw n,g,d, observed setting, original source URL and checked date.
3. Make separate independent-site means for settings 1..6. If a setting has no verified test, mark **設定別実戦値未確認**, not 0, interpolated, carried over from a different model, or filled from maker odds. A single site's verified trial is usable as a provisional one-site reference only with sample-size caveat, not falsely labelled multi-site mean.
4. Retain individual original values and site deviations; review sample size and definition differences in audit. Reflect estimation uncertainty in official Evaluation stage as determined by v8.5 contract, with no invented sample-to-setting conversion.
5. Build Binomial grape successes over one eligible A-type total G counter, where definition must exclude bonus-internal spins, and avoid duplicate denominator input. BIG/REG and grape joint per-spin outcomes are not automatically independent: verify likelihood factorization before adding grape to bonus likelihood; total BIG/REG unaffected.
